# موقع المهندس كريم الدين - الملف التعريفي والمشاريع (Portfolio Website)

موقع تعريفي شخصي واستعراضي (Portfolio Website) للمهندس **كريم الدين أحمد** (مهندس برمجيات متقدم ومتخصص في بناء الأنظمة السحابية، تطبيقات الويب، وأنظمة إدارة المؤسسات ERP / Odoo).

---

## 📌 أقسام الموقع الرئيسية (Website Sections)

يتكون الموقع من الأقسام التالية المُصممة بشرائح وتأثيرات بصرية تفاعلية (RTL):

### 1. الشريط العلوي والقائمة (Navigation Bar & Floating Actions)
* **القائمة العائمة (Navbar):** شريط تنقل ثابت أعلى الصفحة بتصميم عصري يتيح التنقل السلس بين الأقسام.
* **قائمة الهواتف الذكية (Mobile Burger Menu):** قائمة استجابة سريعة متوافقة مع جميع الشاشات.
* **زر الواتساب السريع:** زر عائم مثبت أسفل الشاشة للتواصل المباشر عبر WhatsApp.

### 2. القسم الرئيسي (Hero Section - `#home`)
* نبذة تعريفية سريعة بالمهندس كريم الدين وتخصصه في تطوير الأنظمة السحابية والويب وأنظمة الـ ERP.
* صورة شخصية دائرية مع تأثيرات إضاءة وحركة زجاجية مضاءة.
* زر دعوة لاتخاذ إجراء (CTA) للانتقال المباشر إلى قسم التواصل.

### 3. قسم المهارات والخبرات التقنية (Skills & Expertise Section - `#skills`)
شبكة تفاعلية تعرض المهارات التقنية والتقنيات التي يجيدها المهندس مع أيقونات وألوان مميزة لكل تقنية:
* **تطوير الويب الواجهة الأمامية:** HTML, CSS, JavaScript, Bootstrap.
* **تطوير الخلفية والأنظمة:** Java, JavaFX, Spring Boot, Python, Data Structures.
* **قواعد البيانات:** MySQL DB, PostgreSQL.
* **أنظمة إدارة المؤسسات وإدارة السيرفرات:** Odoo Implementation, ERP Systems, Linux Administration.

### 4. قسم المشاريع المعروضة (Projects Showcase Section - `#projects`)
معرض تفاعلي للمشاريع المزودة بسلايد شو (Slideshow) لكل مشروع لاستعراض الصور مع أزرار التنقل والروابط المباشرة:
1. **نظام إدارة مطعم متكامل مزود بالذكاء الإصطناعي (ERP System):** نظام شامل يشمل الكاشير، المنيو، وحجز الطاولات مع شات بوت ذكاء اصطناعي (مع رابط فيديو تجريبي).
2. **نظام إدارة متجر إلكتروني:** يتيح إدارة المنتجات، العروض، الفواتير، والتقارير (مع رابط فيديو تجريبي).
3. **موقع إلكتروني لشركة إستشارات هندسية (رواق):** استعراض مشاريع الشركة وحاسبة تقديرية لتكاليف التشطيب (مع رابط معاينة مباشر).
4. **موقع إلكتروني لشركة براندنج وتسويق إلكتروني (طفرة ميديا):** يعرض خدمات التسويق، النتائج وفورم حجز استشارات (مع رابط معاينة مباشر).
5. **موقع إلكتروني لعيادة طبيب أسنان (الطيب):** استعراض الخدمات، صور قبل وبعد، وحجز الجلسات (مع رابط معاينة مباشر).
6. **موقع إلكتروني لشركة المكتب الفني للمقاولات (TOC):** استعراض مشاريع ونطاق خدمات المقاولات والاستشارات الهندسية (مع رابط معاينة مباشر).

### 5. قسم حجز الجلسات الاستشارية (Booking Session Section - `#booking`)
* نموذج تفاعلي بحقول إدخال موثقة يتيح للعملاء إدخال الاسم، رقم الهاتف، رقم الواتساب، البريد الإلكتروني، وتحديد نوع النشاط التجاري (مطعم، شركة خدمات، أكاديمية، إلخ).
* يتصل مباشرة مع مكتبة **EmailJS** لإرسال بيانات الحجز فورياً إلى البريد الإلكتروني.

### 6. قسم التواصل والذيل (Contact & Footer Section - `#contact`)
* عرض قنوات التواصل المباشرة (رقم الهاتف والواتساب: `+201066571355`).
* روابط شبكات التواصل الاجتماعي (LinkedIn, Facebook, YouTube).
* حقوق الملكية والنشر.

## 🛠️ التقنيات المستخدمة (Technologies Used)

* **HTML5 & CSS3:** بناء هيكلي كامل يدعم الاتجاه من اليمين إلى اليسار (RTL).
* **Tailwind CSS (CDN):** لتنسيق الواجهات والتجاوب السريع مع مختلف الشاشات.
* **JavaScript (Vanilla JS):** للتحكم في القائمة المحمولة، السلايد شو، ومعالجة النماذج.
* **Font Awesome 6.4.0:** الأيقونات والرموز البرمجية والشبكات الاجتماعية.
* **AOS (Animate On Scroll):** للحركات والتأثيرات البصرية أثناء التمرير.
* **EmailJS:** لإرسال الرسائل والنماذج مباشرة عبر الجانب العميل (Client-side).
